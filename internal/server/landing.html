Tollgate Running

One OpenAI-compatible endpoint for many LLM providers.

Tollgate is a gateway written in Go. It sends each chat request to Groq, Gemini or Anthropic, falls back when one fails, caches repeats, rate-limits each API key and records what every request cost. Gateway overhead is 0.2 ms at p50.

Read the docs View source on GitHub Design notes

What it does

Routing and fallback

Aliases like tollgate/cheapest try models in order; a failing provider trips a circuit breaker.

Cost ledger

Every request is priced from the model catalog and recorded in Postgres, per API key.

Rate limits per key

Requests per minute and tokens per minute, checked atomically in Redis.

Response cache

Repeated temperature: 0 requests are answered from cache at no upstream cost.

Try it

curl https://tollg.duckdns.org/v1/chat/completions \
  -H "Authorization: Bearer $TOLLGATE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"tollgate/cheapest","messages":[{"role":"user","content":"hi"}]}'

Requests need a Tollgate API key. To run your own gateway, follow the deploy guide in the README.
